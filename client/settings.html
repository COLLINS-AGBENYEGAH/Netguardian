Agent Token

Your standalone Agent (which runs on your own network to actually discover devices) uses this token to authenticate its reports. Generating a new one immediately invalidates the old one - update your Agent's .env file if you regenerate.

Download Agent gives you a ready-to-run copy of the Agent with a fresh token already configured — unzip it, run npm install, then npm start. Either button generates a new token, which invalidates any token currently in use — only use one or the other, not both back to back.
